# Examples

**Status:** The Fedora prototype has runnable examples through the `sam` CLI. This directory
still holds no standalone samples; see `docs/fedora-prototype.md` for the CLI.

When implementation begins, this directory should hold small, honest examples:

- a request and its typed response;
- an out-of-domain handoff;
- an ambiguous query and its clarification;
- a registry entry with its handler contract;
- a lexical-only retrieval demonstration;
- a cache hit and its invalidation.

Every example must be generated by running the real implementation. Do not write illustrative
output and label it as behaviour.
